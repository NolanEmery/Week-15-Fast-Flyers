# Week-15-Fast-Flyers
Plan It:

What is the goal of the website?
To make flyers quickly.

Who are you building for, and what do they care about?
The target audience is people who want to make flyers quick. 

Describe the flyer creation flow from opening the tool to exporting a PDF. What should users see first, and what happens next?
Include a canvas in the middle. Include a bar at the top (for editing). Include an AI helper on the right (to help with formatting). Support drag and drop. Include a text option. Include fonts and pictures that can be imported from Google. Include templates. 

What is the minimal set of features needed for the first version?
AI formatter. Drag and Drop. Text. Fonts and Pictures from Google. Templates.

What should users be able to add or change on the flyer?
Images, text, and fonts.

What words best describe the look and feel of the tool?
Efficient, easy to use.

Test It:

No changes necessary.

Expand It:

How did you add design guardrails like templates, font limits, palettes, or alignment helpers?
Have user created templates. Include at least three. Users can use publicly available templates.
